# Program team titles setup

1. In the Future of Music Supabase project, open **SQL Editor**.
2. Create a new query, paste [program-administration-team-setup.sql](./program-administration-team-setup.sql), and select **Run**.
3. Refresh Administration Hub.

Existing program team accounts start as **Program Coach**. In Program Administration → Team accounts, the owner can change any person’s title (for example, Managing Director, Teaching Artist, or Program Staff) and choose a title when creating a new invitation.
